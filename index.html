CORE CONCEPT

Queue Operations

Understand how each operation works in a Queue ADT.

＋

Enqueue

Adds a new element at the rear of the queue.

Time: O(1)
−

Dequeue

Removes the element from the front of the queue.

Time: O(1)
◉

Peek

Displays the front element without removing it.

Time: O(1)
＃

Size

Returns the number of elements in the queue.

Time: O(1)

REAL WORLD

Queue in Everyday Life

Queue ADT is used in many real-world systems.

🎓

College Canteen

Students join the queue and are served in the same order they arrive.

Student 1 Student 2 Student 3 → Service
🎟️

Ticket Counter

Customers receive service based on their arrival order using FIFO.

Person A Person B Person C → Counter
🏥

Hospital Tokens

Token numbers help organize patients waiting for their turn.

Token 101 Token 102 Token 103 → Doctor
